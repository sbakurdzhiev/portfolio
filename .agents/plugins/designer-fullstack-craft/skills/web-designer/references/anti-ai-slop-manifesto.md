# The Anti-AI Slop Manifesto

AI-generated web designs often suffer from recognizable, repetitive tropes:
1. **The "Cyber-Purple" Cliché**: Every site having the exact same indigo-purple radial gradient background on `#09090b`.
2. **The "Float & Blur" Fallback**: Random floating blurred circles behind standard rounded cards.
3. **Impersonal Placeholders**: "Transforming digital experiences with synergistic paradigm shifts" instead of authentic, concrete engineering achievements.

## How to Craft Distinctive, Human-Grade Interfaces
- **Authentic Subject Matter**: If designing for DevOps/SRE, use real terminal shells, `kubectl` syntax, pipeline stages, latency counters, and CRD manifests.
- **Surface Texture & Depth**: Subtle geometric grids, CRT phosphor decay, tactile borders, bracket corners, and clean status ribbons.
- **Real Interactivity**: Rather than static mockups, build real working features: working command interpreters, live pipeline runners, sound effect toggles, and stateful inspectors.
