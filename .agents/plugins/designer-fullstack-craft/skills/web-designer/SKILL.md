# Web Designer & UI/UX Craftsmanship Skill

Use this skill whenever you are asked to act as a web designer, build a landing page, design a portfolio, craft UI components, or elevate visual polish.

## Core Design Principles

### 1. Eliminate Generic AI Slop
- **What is AI Slop?** Generic black backgrounds with random purple/pink neon glows, standard rounded rectangles with default blur, meaningless floating spheres, and repetitive marketing buzzwords.
- **The Remedy:**
  - Build with **thematic authenticity** (e.g. for a DevOps engineer: authentic TUI/CLI elements, real Kubernetes CRD layouts, terminal scanline toggles, `htop`-style resource bars).
  - Use deliberate editorial layouts: Bento grids, split-view consoles, tactical HUDs, asymmetric balance.

### 2. Typography & Contrast Hierarchy
- Establish a three-tier typographic scale:
  - **Display / Hero**: Bold, confident, high impact (`text-2xl` to `text-5xl`).
  - **Subheaders & Labels**: Monospace or clean grotesque with tracking (`tracking-wider`, `text-xs uppercase`).
  - **Body / Documentation**: High readability with comfortable line-height (`text-sm leading-relaxed`).
- Ensure contrast ratios meet WCAG AA standards (`>= 4.5:1`).

### 3. Micro-Interactions & Animation Standards
- Transitions should be fast and snappy: `duration-150` to `duration-250` with `ease-out` curves.
- Use spring-like hover states, subtle glowing borders (`box-shadow`), and tactile button active states.
- Support user preferences: honor `@media (prefers-reduced-motion: reduce)`.
